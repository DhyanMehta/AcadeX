This folder contains the complete machine learning pipeline for the Early Academic Risk Detection system. It includes exploratory data analysis, XGBoost-based multi-class risk classification (Low / Medium / High) trained on 50,000 student records with SMOTE for class imbalance, SHAP explainability for per-student risk reasoning, LSTM-based trend prediction for failure forecasting, and 5-Fold Cross Validation achieving 98.72% mean accuracy with ±0.10% variance.
